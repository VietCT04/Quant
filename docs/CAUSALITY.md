# Causal research boundaries

A five-second bar starting at 00:00:00 with 100 ms lag is observable at 00:00:05.100 UTC. The native engine requires an eligible later executable price and respects latency. Arbitrary supplied arrays do not certify their own provenance.

`q.features` evaluates registered causal operations and carries the block's availability. Resampling waits for all inputs. `q.simulator.targets` masks unavailable source cells and retains the input clocks. The simulator wrapper rejects targets that arrive after their assigned decision. Assign delayed features to a later decision explicitly. Use only already observable equity for dynamic sizing.

`q.evaluate.Labels` has forward dependencies and cannot be implicitly converted to an array or bound to a target. Diagnostics accept the label object directly. `research_values` explicitly exposes an array for research. Code that deliberately extracts the array owns the information boundary.

Default EMA resets at unknown values. The migrated native EMA reference specifies its historical carry convention and retains existing execution checks. Test causal prefixes by changing future inputs. Test streaming state with multiple chunk sizes and unknown coverage.

Ordinary research uses the entire authorized archive. Forward labels stay inside the requested evaluation interval. V2 order decisions use completed-bar timestamps at zero processing latency, with execution at the immediately following scheduled open. See [the research protocol](RESEARCH_PROTOCOL.md).
